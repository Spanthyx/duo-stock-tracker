# Duo Stock Tracker

A personal Python project to monitor Apple Store availability of the Apple iPhone Duo and notify me when it becomes available.

## Project Goals

- Check product availability on the Apple Store website.
- Send notifications when the product becomes available.
- Automate availability checks using AWS Lambda and scheduled triggers.
- Store historical availability data to identify patterns over time.

## Current Status

🚧 Work in progress — initial development.

## Planned Approach

The project will start as a local Python script running on macOS. Once the basic availability checks work reliably, I plan to explore cloud deployment, notifications, and persistent data storage.
